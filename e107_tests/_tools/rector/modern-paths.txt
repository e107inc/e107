# Repo-relative path prefixes that are tracked but intentionally modern PHP.
#
# The shipping tree is downgraded to PHP 5.6 and the floor lint asserts that.
# Everything listed here is exempt: it is developer or CI tooling that runs on
# the maintainer's PHP, never on a user's server, so it is free to use modern
# syntax. These prefixes mirror the correctness path skips in rector.php; keep
# the two in step.
#
# Contract: one path prefix per line, relative to the repository root, no
# leading "./" and no trailing slash. Blank lines and lines whose first
# non-space character is "#" are comments. A prefix matches a file when the
# file's repo-relative path is the prefix itself or starts with the prefix plus
# a "/". Consumed by bin/php-floor-lint with a shell `read` loop, and readable
# by any PHP consumer via file() with FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES.
